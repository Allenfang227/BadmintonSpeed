# 杀球测速 BadmintonSpeed 🏸

羽毛球杀球测速 App —— 通过视频分析自动检测羽毛球轨迹、计算杀球速度。

> 依据《杀球测速App技术设计文档》实现（MVP 版本：第 9.3 阶段 + 第 4.7.2 简化方案：白色球亮度检测替代 YOLO、手动标定场地四角替代场地检测模型）。

## ✨ 功能

- 🎥 **视频导入**：从相册选择含杀球过程的横屏视频
- 📐 **场地标定**：点按画面中的场地四角（左上→右上→右下→左下），自动透视换算为标准双打场地（6.10 m × 13.40 m）
- 🤖 **球路检测**：亮度阈值 + 连通域分析识别白色羽毛球，卡尔曼式预测跟踪
- ⚡ **速度计算**：帧间位移 ÷ 时间 → 瞬时速度（km/h），移动平均平滑
- 🏸 **击球识别**：速度局部峰值判定杀球（≥140 km/h）、平抽、吊球等
- 📊 **结果展示**：最高球速大字展示、球路轨迹回放、速度-时间曲线、击球明细
- 📁 **历史记录**：每次测速自动保存，可回看、删除
- 🔒 **隐私安全**：全部计算在手机本地完成，视频不上传

## 🚀 安装

进入仓库 **Releases** 页面下载 `BadmintonSpeed-v1.0.0.apk`，传到手机后点击安装。

- 支持 Android 8.0（API 26）及以上
- 首次安装需在系统设置中允许"安装未知来源应用"

## 📱 使用步骤

1. 横屏拍摄一段包含完整杀球过程的视频（球需清晰可见、光线充足）
2. 打开 App → 点击「开始测速」选择视频
3. 按顺序点击画面中的场地四个角
4. 等待自动分析，查看球速结果

## 🛠️ 技术栈

- 语言：Kotlin 1.8.21
- UI：Jetpack Compose（Material 3，深色主题）
- 构建：AGP 7.4.2 / Gradle 7.6.4，compileSdk 33 / minSdk 26
- 架构：MVVM + Repository，纯本地计算（无 JNI / OpenCV / TFLite 依赖）

## 🔨 本地构建

```bash
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk
gradle assembleRelease
```

Release 产物：`app/build/outputs/apk/release/app-release.apk`（已用 `release.keystore` 签名，可直接安装）。

## ⚠️ 已知限制（MVP）

- 视频分析依赖光线与球体对比度，暗光环境下准确率下降（可在设置中调低亮度阈值）
- 一次分析当前最多 3 分钟视频（超出自动截取前 3 分钟）
